# tŷ lettings — website revamp mock-ups

Mock-ups prepared by Creadigol Design for the pitch to TY Lettings Ltd (tylettings.com),
whose current site we built six years ago.

Both mock-ups are single, self-contained HTML files — open them directly in a browser.
Photography is represented by placeholders; real property photos drop straight in.

## Basic revamp — £1,000 (`basic-revamp/index.html`)

A modern refresh keeping the current site's simple structure:

- Clean, contemporary look (Archivo / Karla type, sea-green palette)
- Fully responsive, mobile-first layout
- Sticky navigation, clear calls to action
- Tidy property cards with bedroom badges and key features
- Trust strip (Rent Smart Wales, local & independent)
- Contact section with enquiry form
- Same page structure as today, so content migrates straight across

## Full revamp — £3,000 (`full-revamp/index.html`)

A complete redesign with a new brand identity and richer functionality:

- New identity built on the "to bach" idea — the circumflex in *tŷ* is Welsh for
  "little roof", used as the brand's roof motif throughout
- Distinctive slate-and-gorse palette, Bricolage Grotesque display type
- Bilingual English / Cymraeg toggle (working demo on key content)
- Filterable property grid (by number of bedrooms) with amenity chips and
  360° tour placeholders
- Brand story, student "how it works" journey, area guide with illustrated map,
  testimonials, and a real-questions FAQ
- Scroll animations and hover micro-interactions (respecting reduced-motion)
- Prominent WhatsApp / same-day-reply contact flow
